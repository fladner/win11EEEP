# Modelo Selenium com Java

O Selenium não é um aplicativo global: ele é adicionado como dependência de cada projeto. Este modelo usa Java 21, Maven e Selenium 4.47.0.

1. Abra esta pasta no VS Code, NetBeans ou Eclipse.
2. Execute `mvn package` para baixar as dependências e compilar.
3. Rode `ExemploSelenium.java` pela IDE.

O exemplo usa o Microsoft Edge, que já acompanha o Windows 11. O Selenium Manager cuida do driver compatível na primeira execução, desde que haja acesso à Internet.
