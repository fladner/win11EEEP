# Spring Framework / Spring Boot

Spring não é instalado como um programa do Windows. O ambiente necessário já foi preparado com Java 21, Maven, VS Code e o pacote de extensões Spring Boot.

Para iniciar um projeto:

1. Abra <https://start.spring.io/> pelo atalho criado na área de trabalho.
2. Selecione Maven, Java e a versão de Spring Boot adotada pelo professor.
3. Use Java 21, escolha as dependências da aula e baixe o projeto.
4. Extraia o projeto e abra a pasta no VS Code, NetBeans ou Eclipse.
